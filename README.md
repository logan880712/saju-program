# 사주정원 v2 — 종합 사주·운세 웹앱

휴대폰 브라우저에서 출생 정보를 입력하고 원국, 사주 풀이, 대운, 올해·내년 운세, 월운, 오늘의 일진을 확인하는 React + TypeScript 웹앱입니다. 주소: https://logan880712.github.io/saju-program/ . GitHub Pages 배포 작업이 성공해야 접속할 수 있습니다.

## 사용할 수 있는 기능

- 이름·성별·양력/한국 음력·윤달·생년월일·시각·한국 출생지역 입력
- 년주 | 월주 | 일주 | 시주, 천간·지지·오행·음양·십성·지장간
- 일간 이미지, 재물·직업·배우자 관계·변화·오행의 여섯 가지 규칙 기반 풀이
- 성별·년간 음양에 따른 순역, 분 단위 기산, 10개 대운, 현재 대운 표시 및 각 구간 풀이
- 올해·내년의 연운, 조회 연도 선택, 원국·대운과 연운의 관계
- 실제 12절 절입 시각에 따른 월운과 날짜별 구간, 원국과의 관계
- 첫 화면에서 입력 없이 보는 공통 일진, 누구의 출생정보든 입력해 바로 보는 개인별 오늘 운세
- 오늘 운세 전용 주소: https://logan880712.github.io/saju-program/?view=today
- 다른 사람 입력 시 화면 입력값과 리포트를 초기화하며, 기존 저장정보는 덮어쓰지 않음
- 쌍별 천간합·육합·충·형·파·해 및 풀이 근거
- 출생정보 기기 저장·불러오기·삭제(사용자가 체크한 경우만 저장)
- 원국 JSON / 전체 리포트 JSON 다운로드, 전체 리포트 인쇄·PDF
- 서버·계정·API 키 없이 브라우저 안에서 계산

## 중요한 계산·해석의 구분

`src/engine/`에서 구조화된 계산 결과를 생성하고, `src/interpretation/readings.ts`가 **완료된 계산 결과만** 읽어 문장을 만듭니다. 해석이 원국·간지·운을 생성하거나 수정하지 않습니다. 현재는 공개된 전통 배속의 **규칙 기반 해석**이며 AI 호출은 없습니다. AI 제공자 계약은 별도로 유지합니다. 통계적으로 검증된 성격 판정이나 미래 사건 예측을 제공한다고 주장하지 않습니다.

풀이 버전 `traditional-rules-v2`는 월지의 계절·본기 십성, 표면 배속과 추가 지장간 배속, 일간과 같은 오행의 지장간(통근 자료)을 구분합니다. 겉에 식상이 없더라도 지장간에 있으면 누락하지 않습니다. 나무의 뿌리, 서랍 속 재료, 집안 살림 같은 비유와 편한 해요체로 설명하고, 계산 근거와 해석 한계는 펼쳐볼 수 있습니다.

모든 풀이에 일간·십성·쌍별 관계 등의 근거를 표시합니다. 운세 점수, 결혼일, 부자가 되는 시기 등을 임의로 생성하지 않습니다. 신강·신약, 용신·희신, 합화, 삼합·삼형의 완성, 두 사람의 궁합은 아직 구현하지 않았습니다.

## 실행·검증

Node.js 22.12 이상(클라우드 검증 24.19.0)과 npm이 필요합니다.

```sh
cd /workspace/saju-program
npm ci --cache /tmp/saju-npm-cache
npm test
npm run build
npm run dev -- --port 5173
```

```sh
SAJU_CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
npm run build:offline
SAJU_CHROMIUM_PATH=/usr/bin/chromium npm run test:offline
```

일반 PC에서 Playwright 브라우저가 없다면 `npx playwright install chromium`으로 신뢰할 수 있는 기본 다운로드를 설치하고 `npm run test:e2e`를 실행합니다. 클라우드에는 `/usr/bin/chromium`이 이미 있습니다.

계산 테스트는 원국·한국 음력·표준시 이력·절입 경계·대운 기산과 순역·연운·월운·일진·쌍별 관계·해석 데이터 불변성을 검증합니다. 대운 기산 회귀값은 upstream의 공개 `Yun.test.js` test5·test6을 한국 시각으로 변환해 대조합니다: https://github.com/6tail/lunar-javascript/blob/master/__tests__/Yun.test.js . 이것은 엔진 회귀 검증이며 KASI 공인 검증을 뜻하지 않습니다.

브라우저 테스트는 PC/390px 모바일에서 출생정보→원국, 모든 리포트 탭, 대운·월운 선택, 연도 변경, 성별 미선택, 저장·복원·삭제, JSON 다운로드, 전체 PDF 생성, 화면 넘침 및 실행 오류를 검사합니다. 첫 화면의 공통 일진, 개인별 오늘 운세 바로 진입, 사람 변경 시 독립 계산, 오늘 운세 전용 링크도 검사합니다. 저장은 기본적으로 꺼져 있습니다.

## 계산 계약

- **출생 범위:** 양력 변환 후 1950-01-01~2030-12-31, 한국 출생. 음력 1949년 말이 양력 1950년이면 지원하고, 음력 2030년 말이 양력 2031년이면 거부합니다. 존재하지 않는 날짜·윤달·시각을 추측값으로 대신하지 않습니다.
- **한국 음력:** `korean-lunar-calendar@0.4.0`의 한국 달력 테이블. 중국 음력으로 대체하지 않습니다. https://github.com/usingsky/korean_lunar_calendar_js
- **간지·절기·대운 엔진:** `lunar-javascript@1.7.7`. https://github.com/6tail/lunar-javascript
- **년주·연운:** 입춘 절입 시각부터 다음 입춘 직전까지. 월주는 음력 월초가 아닌 12절의 절입 시각부터 전환합니다.
- **역사적 시각:** 출생기록의 당시 시계 시각을 입력합니다. IANA tzdb 2026b의 Asia/Seoul 이력을 앱에 포함합니다. https://data.iana.org/time-zones/releases/tzdata2026b.tar.gz
- 1954-03-21 전환부터 1961-08-10 전환까지 표준시 UTC+8:30, 나머지는 UTC+9. 1950~1951, 1955~1960, 1987~1988의 해당 기간에 서머타임을 제거합니다. 실제 UTC 순간을 UTC+8로 변환하여 엔진의 절기와 비교하고, 일주·시주는 서머타임을 제거한 당시 표준시로 계산합니다.
- 예: 1988-07-12 01:30 당시 시계 → 표준시 00:30 → 자시. 1988-05-08 02:30은 존재하지 않고, 1988-10-09 02:30은 두 번 존재하므로 원국을 결정하지 않고 오류를 표시합니다.
- **일주:** 23:00 표준시 자시 시작에 다음 일자로 전환(`sect=1`). 야자시/조자시 별도 규칙은 미지원입니다.
- **대운:** 양남·음녀 순행 / 음남·양녀 역행. 인접 절까지의 시간 차를 3일=1년으로 환산하는 분 단위 기산법(`getYun(gender,2)`). 라이브러리의 대운 개시일을 역사적 한국 표준시로 표시합니다. 실제 개시 시각을 기준으로 각 10년 구간을 판정하며, pre-onset placeholder를 첫 대운으로 표시하지 않습니다. 나이는 개시까지의 경과연수(약식)이며 세는나이나 정확한 만 나이를 뜻하지 않습니다. 학파별 기산법과 반올림은 다를 수 있습니다.
- **연운·대운 관계:** 해당 조회 연도 7월 1일 기준 대운과 비교합니다. 그해 대운이 바뀌면 전후 구간은 따로 읽어야 합니다.
- **월운:** 입춘~경칩의 인월부터 다음 해 소한~입춘의 축월까지. 1~12월이나 음력 월과 같지 않습니다.
- **일진:** 한국 날짜의 정오 기준 날짜 간지입니다. 23시 이후는 다음 일진으로 보며, 현재 시각의 자동 23시 전환을 별도로 제공하지 않습니다.
- **십성:** 일간 기준 오행 생극·음양. 일간 자체는 일원. 지지 십성은 본기 기준이며 각 지장간 십성도 원국에서 표시합니다.
- **지장간:** 본기 먼저. 자=계, 축=기·계·신, 인=갑·병·무, 묘=을, 진=무·을·계, 사=병·무·경, 오=정·기, 미=기·정·을, 신=경·임·무, 유=신, 술=무·신·정, 해=임·갑. 비율·사령·가중치는 미계산입니다.
- **오행 개수:** 천간·지지 8글자 단순 집계이며 신강·신약·용신 판단이 아닙니다. 구조 자료는 일간을 제외한 천간 3 + 지지 본기 4의 7개 배속과 추가 지장간을 별도 저장합니다. 본기를 중복 집계하거나 임의의 강도·가중치를 부여하지 않습니다.
- **합충 관계:** 천간합·육합·충·형·파·해 쌍별 표입니다. 합은 좋은 일, 충은 불행이라고 단정하지 않습니다. 인사신/축술미의 형은 쌍별 배속으로만 표시하며 삼형 완성·강도를 평가하지 않습니다.
- **지역:** 기록용이며 경도·균시차·진태양시 보정은 없습니다. 이름은 계산에 영향을 주지 않고 성별은 대운 순역에 사용합니다. 성별 미선택 시 대운만 보류합니다.

## 배포와 설치 없는 파일

`.github/workflows/pages.yml`은 main의 계산 테스트·빌드 후 완성된 단일 HTML을 GitHub Pages에 배포합니다. 저장소의 Settings → Pages → Source에서 GitHub Actions를 선택합니다. 루트 `index.html`도 생성된 단일 파일이므로 main 브랜치 루트 게시를 선택한 경우에도 소스 TypeScript를 직접 로드하지 않습니다. 개발 원본 진입점은 `app.html`입니다.

`npm run build:offline`은 루트 `index.html`, `standalone/saju-program.html`, `downloads/saju-program.html`을 갱신합니다. 이 명령은 추적된 배포 파일을 변경하므로 일반 환경 설치에서는 `npm run build`를 사용하고 앱 배포 변경 작업에서만 생성 파일을 커밋하세요. ZIP 파일은 같은 HTML을 포함하도록 배포 때 갱신합니다.

단일 HTML을 PC에 저장해 Chrome/Edge로 열면 서버·인터넷 없이 쓸 수 있습니다. 모바일은 GitHub Pages 웹 주소를 사용하세요. 클라우드 관리형 Chromium은 file:// 탐색을 차단하므로 offline 테스트는 HTML 원문을 인터넷 차단 빈 페이지에 주입해 검증합니다.
