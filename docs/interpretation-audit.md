# 명리 풀이·입력 개선 점검 — 2026-10-08

## 확인한 문제와 수정

- 오늘의 간지·일간 기준 십성을 밝히기 전에 추상적 비유가 반복되어 개인별 계산과 설명의 연결이 보이지 않았다. 첫 답변과 근거 카드에 실제 일간·일진·천간 십성·지지 본기 십성을 표시하고, 다음 이야기에서 원국의 해당 기둥과 관계를 읽도록 바꿨다.
- 원국의 천간 3개와 지지 본기 4개로 만든 7개 배속을 천간에 모두 드러난 배속처럼 표현할 여지가 있었다. 천간, 지지 본기, 추가 지장간을 구별하고 해당 기둥·글자·십성을 밝힌다.
- 같은 일간의 사용자에게 비슷한 일진 비유만 나왔다. 월지·지장간과 실제 합충 관계가 다른 원국은 다른 근거와 이야기를 사용한다. 합·충·형 등을 사건 확정이나 길흉 점수로 바꾸지는 않는다.
- 조회 연도와 오늘 날짜를 혼동하면 배경 세운·월운이 틀릴 수 있었다. 오늘 배경은 조회 날짜의 한국 표준시 정오로 따로 계산한다. 연운의 대운 배경은 해당 조회 연도 7월 1일을 사용한다.
- 상담 화면과 상세 리포트·PDF·JSON의 문장이 달랐다. 원국 6개 주제·연운·오늘 풀이에 동일한 상담 생성기를 연결했다. 월운·선택한 개별 대운은 그 구간의 별도 리포트를 유지한다.
- 미래 출생 정보를 입력했을 때 출생 전 월운을 개인 운세처럼 설명하던 부분을 막았다. 완전한 출생 전 구간은 안내만 표시하고, 출생을 걸친 구간은 출생 이후 시각부터 참고하도록 명시한다. 계산 간지·십성 자료는 보존하며 오늘·연운도 출생 전 안내를 사용한다.
- 모바일 날짜 선택기의 반복 조작을 줄이기 위해 숫자 8자리 입력을 추가했다. 미완성 날짜를 입력하면 이전 원국을 비우고, 유효한 날짜만 계산한다. 한국 음력 30일을 양력 검증으로 잘못 거부하지 않는다.

## 검증 기준

자동 검증은 독립적으로 고정한 간지·십성·쌍별 관계 기대값과 날짜 경계, 원국·운 데이터 불변성, 상담과 리포트 연결을 검사한다. 예를 들어 2026-10-08 을묘일을 정화 일간은 편인·편인, 무토 일간은 정관·정관으로 읽는다. 일간이 같아도 월지 자수/인목이 다른 원국은 자묘형의 월주 연결 여부가 다르다. 2026-10-08 한로는 한국 시각 15:29:17이므로 정오 배경 월운은 정유, 다음 날은 무술로 계산한다.

PC·모바일 브라우저에서 숫자 입력, 명리 근거 표시, 이야기 진행, 저장·복원, 다른 사람으로 전환, 상세 리포트·JSON·PDF를 검사한다. 단일 HTML은 외부 네트워크 요청 없이 따로 검증한다. 테스트 통과는 이 계산 계약과 회귀 검증의 결과이며, 모든 학파의 해석이나 KASI 공인 검증을 뜻하지 않는다.

## 외부 사주 앱 비교 상태

사용자가 요청한 여러 앱의 실제 공개 화면 비교는 **아직 완료하지 못했다**. 이 환경에서 App Store, Google Play, 공식 사이트, 검색 페이지에 접근하면 프록시의 `403` 응답으로 차단된다. 다른 앱을 직접 조사한 것처럼 기능이나 말투를 보고하지 않는다.

환경 설정 초안에 `itunes.apple.com`, `apps.apple.com`, `play.google.com`, `www.forceteller.com`, `www.jeomsin.co.kr`, `www.google.com` 접근을 추가해 저장했다. 해당 초안은 환경 설정 화면에서 검토·저장한 뒤 환경을 게시해야 적용된다. 앱 자체의 GitHub Pages 배포와는 별개의 환경 설정이다.

접근 가능해지면 점신·포스텔·천명·귀자할매 등의 실제 공개 설명을 출처·확인 날짜와 함께 비교할 계획이다. 비교 항목은 생년월일 숫자 입력, 양력·음력·윤달·시간 미상 처리, 절기/자시 계산 기준 공개, 개인 원국과 운의 연결, 풀이의 반복 여부, 근거 펼치기, 오늘 운세 진입, 모바일 가독성이다. 특정 서비스의 독자 캐릭터나 문장을 복제하지 않는다.
